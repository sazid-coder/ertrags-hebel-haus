# Profit Lever System

Create a premium, high-end B2B consulting website for a German company called:

ERTRAGSMANUFAKTUR

Core positioning:

“Private-Equity-Disziplin. Mittelstandsrealität. Umsetzungskraft.”

Core promise:

“Wir machen Unternehmen profitabler, liquider und wertvoller.”

The company works with owner-led German Mittelstand companies to identify and execute the economic levers that can increase profit, liquidity, enterprise value and entrepreneurial freedom.

The website must feel like a combination of:

- Premium management consultancy

- Private-equity value creation

- Strategic business advisory

- Hands-on operational transformation

- Sophisticated German Mittelstand brand

IMPORTANT:

Do NOT make this look like a generic consulting website.

Do NOT use the typical corporate blue-gradient SaaS aesthetic.

Do NOT use excessive stock photos of businessmen shaking hands.

Do NOT make it look like a startup landing page.

Do NOT make it feel like a financial institution.

Do NOT overload the design with charts everywhere.

The visual language should communicate:

PRECISION

AUTHORITY

ECONOMIC DISCIPLINE

TRUST

CLARITY

EXPERIENCE

RESULTS

IMPLEMENTATION

PREMIUM GERMAN BUSINESS

The design should be editorial, sophisticated, spacious and highly structured.

19. RESPONSIVE DESIGN

==================================================

The website must be fully responsive.

Desktop:

12-column editorial layout.

Tablet:

8-column layout.

Mobile:

4-column layout.

Important mobile rules:

- Hero typography should remain large but fit naturally.

- Never create horizontal overflow.

- Preserve the hierarchy of the desktop design.

- Convert horizontal process diagrams into vertical flows.

- Convert multi-column service sections into stacked editorial blocks.

- Keep numbers large.

- Maintain generous spacing.

- Buttons should be easy to tap.

- Navigation becomes a clean mobile menu.

- Images must crop intelligently.

- Never simply shrink the desktop layout.

Mobile should feel intentionally designed, not like a compressed desktop website.
